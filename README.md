🎯 Overview
The BShop Navbar is a fully responsive navigation component built with Next.js 14+ and Tailwind CSS. It provides a seamless user experience across all devices with intelligent search and menu interactions.

How It Works
Mobile View (≤ 860px):

Collapsed: Shows logo, hamburger menu icon, and language button

Expanded (click hamburger):

Search bar overlays the entire navbar (hides logo and buttons)

Navigation menu drops down below

Both open together with a single click

Click hamburger again or click outside to close everything

Desktop View (> 860px):

Full navigation links visible

Search bar with category dropdown

Language switcher

Sign In button

✨ Features
📱 Fully Responsive - Works on all screen sizes

🔍 Smart Search - Category filtering with real-time search

🎨 Modern Design - Gradient backgrounds with glass morphism

⚡ Next.js Optimized - Uses Next.js Image component for performance

♿ Accessible - ARIA labels and keyboard support

🎯 TypeScript - Full type safety

🎨 Tailwind CSS - Utility-first styling

🔄 Interactive - Smooth animations and transitions
